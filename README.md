# Sistema de Cadastro de Medicamentos

## Descrição

Sistema desenvolvido em Python para cadastrar, listar e buscar medicamentos.

## Funcionalidades

* Cadastrar medicamentos
* Listar medicamentos
* Buscar medicamentos pelo nome
* Salvar e carregar dados

## Como executar

Com o Python instalado, execute:

python main.py

## Requisitos utilizados

* `if`, `elif` e `else`
* `while` e `for`
* Funções com parâmetros e retorno
* Listas e dicionários
* Leitura e escrita de arquivos
* Git e GitHub

## Arquivos

* `main.py` — código do sistema
* `medicamentos.txt` — armazenamento dos medicamentos
* `README.md` — documentação
